## About

**MyVault** is a personal productivity super-app that puts your daily tasks, study sessions, spending, schedule, projects and motivation in **one secure place**.

It's built **offline-first**: everything works without an account or internet connection, is stored encrypted on your device, and optionally syncs to the cloud when you sign in.

> 💡 _"Small steps count. Set one task and one budget for today, then make it happen."_

## Architecture

MyVault follows a simple **feature-first** structure with a shared `core` layer for models, services and widgets.

```mermaid
flowchart TD
    A[main.dart] --> B[SyncManager.initialize]
    A --> C[NotificationService.init]
    A --> D[DailyReminderService.schedule]
    A --> E[MyApp]
    E -->|not signed in & first launch| F[AuthScreen]
    E -->|otherwise| G[HomeScreen]
    F -->|login or skip| G
    G --> H[Dashboard]
    G --> I[Tasks]
    G --> J[Study 🔒]
    G --> K[Money 🔒]
    G --> L[Drawer: Projects 🔒 · Quotes · Values · Constant Goals · Settings]

    subgraph Core
        S[StorageService<br/>AES-encrypted local files]
        M[SyncManager<br/>Firebase Auth + Firestore]
        P[PinService<br/>Secure storage + biometrics]
    end

    I & J & K & L --> S
    S <--> M
    G -.->|section gate| P
```

### How data flows

```mermaid
sequenceDiagram
    participant UI as Screen
    participant SS as StorageService
    participant FS as Encrypted file
    participant SM as SyncManager
    participant CL as Cloud Firestore

    UI->>SS: write(box, data)
    SS->>FS: AES-encrypt & save locally
    SS-->>SM: mark pending change
    Note over SM: Waits for a network connection
    SM->>CL: sync pending changes (if signed in)
    CL-->>SM: newer remote data
    SM-->>SS: merge by updatedAt
```

├── main.dart                  # App bootstrap

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable channel)
- A [Firebase project](https://console.firebase.google.com) _(only needed for account sign-in & sync)_
- Android Studio / Xcode / VS Code with the Flutter extension

### 1. Clone the repo

```bash
git clone https://github.com/aj-aditya19/MyVault.git
cd MyVault/app
```

> The Flutter project lives in the `app/` folder, so run every command below from inside it.

### 2. Install dependencies

```bash
flutter pub get
```

### 3. Create your `.env` file

Create a `.env` file inside the `app/` folder (next to `pubspec.yaml`) and list it under `assets:` in `pubspec.yaml` (the app calls `dotenv.load(fileName: '.env')` at startup):

```env
FIREBASE_WEB_API_KEY=your_web_api_key
FIREBASE_ANDROID_API_KEY=your_android_api_key
FIREBASE_IOS_API_KEY=your_ios_api_key        # also used for macOS
FIREBASE_WINDOWS_API_KEY=your_windows_api_key
```

You only need the key for the platform you're building for, but the app reads it with `!`, so a missing key on that platform will crash at startup.

You'll also need the motivation-messages asset declared in `pubspec.yaml`:

```yaml
flutter:
  assets:
    - .env
    - assets/data/motivation_messages.json
```

> Never commit your `.env` file — add it to `.gitignore`.

### 4. Set up Firebase

1. Create a Firebase project and enable **Authentication → Email/Password**.
2. Create a **Cloud Firestore** database.
3. Register your Android / iOS / Web (and macOS / Windows if needed) apps and update [`app/lib/firebase_options.dart`](app/lib/firebase_options.dart) (or run `flutterfire configure`).

### 5. Run it

```bash
flutter run
```

<details>
<summary><b>Build release versions</b></summary>

```bash
flutter build apk --release        # Android APK
flutter build appbundle --release  # Play Store bundle
flutter build ios --release        # iOS
flutter build web --release        # Web
```

## Security & Privacy

- **Encrypted at rest** — all local data is AES-encrypted, with a fresh random IV for every write.
- **PIN & biometrics** — sensitive sections (Study, Money, Schedule, Projects) stay locked until you authenticate. The PIN is kept in the platform's secure storage (Keychain / Keystore).
- **Works without an account** — nothing leaves your device unless you choose to sign in.
- **Safe password resets** — handled by Firebase's own mail system, so no email credentials are ever embedded in the app.
